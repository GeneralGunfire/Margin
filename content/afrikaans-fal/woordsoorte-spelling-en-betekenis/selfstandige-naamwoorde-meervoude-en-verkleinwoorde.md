> **What you'll learn:** the exact spelling rules for **Meervoude** (plurals: `-e`, `-s`, `-te`, `-de`, `-hede`, `-ere`, `-ers`, irregulars like *skip -> skepe*, *pad -> paaie*, *oog -> oë*), **Verkleinwoorde** (diminutives: `-tjie`, `-djie`, `-etjie`, `-kie`, `-pie`, `-jie`), and **Geslag / Versamelname / Soortname** tested in Grade 11 Paper 1.
>
> **Prerequisites:** short vs long vowels in Afrikaans (`a` vs `aa`, `o` vs `oo`) and open/closed syllables.
>
> **Why this matters:** Single-word morphology (*Gee die meervoud / verkleinwoord / vroulike vorm van die woord tussen hakies*) guarantees 5–8 quick marks in every Paper 1 — provided you remember the exact vowel-doubling/dropping and consonant-doubling spelling rules!

## The idea in plain language

Afrikaans plural and diminutive spelling follows **sound logic** — the spelling changes ONLY to protect how the vowel sounds when you add an ending!

- **Short stressed vowel (`man`, `bal`, `kop`, `bed`):** If you simply added `-e`, *mane* would sound like `"ma-ne"` (long *aa*!). So we **double the final consonant** to keep the vowel short: `man` -> **`manne`**, `kop` -> **`koppe`**.
- **Long twin vowel in closed syllable (`boom`, `skaap`, `muur`, `been`):** When you add `-e`, the first syllable opens up (`bo-me`), which *automatically* sounds long — so we **drop one vowel** (`aa -> a`, `oo -> o`, `ee -> e`, `uu -> u`): `boom` -> **`bome`**, `skaap` -> **`skape`**!

## Part 1: Meervoude (Plurals) — Complete Exam Checklist

```steps
title: Five core plural patterns (plus famous Grade 11 exceptions!)
step: **1. `-e` with vowel/consonant rules:** Short vowel doubles consonant (*kat -> **katte***; *rok -> **rokke***); Twin vowel drops one (*maan -> **mane***; *muur -> **mure***); `f` becomes `w` after long vowel/diphthong (*duif -> **duiwe***; *brief -> **briewe***; *wolf -> **wolwe***); `g` after short vowel drops with **deelteken (`¨`)** or doubles (*oog -> **oë***; *vraag -> **vrae***; *dag -> **dae***; *rug -> **rûe***; *nag -> **nagte***!).
step: **2. `-s` (keeps word readable without changing vowel):** Words ending in unstressed `-el, -em, -en, -er, -aar, -erd, -e` (*lepel -> **lepels***, *onderwyser -> **onderwysers***, *ouma -> **oumas*** — NO apostrophe!).
step: **3. `-te` / `-hede` / `-ere` / `-ers`:** Words ending in **`-g`** after short vowel (*lig -> **ligte***, *gesig -> **gesigte***); **`-heid`** -> **`-hede`** (*moontlikheid -> **moontlikhede*** — drops one `e`? NO: `-hede`!); **`kind -> kinders`**, **`kalf -> kalwers`**, **`lam -> lammers`**, **`goed -> goedere`**, **`volk -> volkere`**.
step: **4. Irregular vowel swaps (`aa -> e` / `i -> e`):** **`stad -> stede`**, **`skip -> skepe`**, **`lid -> lede`**, **`smid -> smede`**, **`pad -> paaie`**, **`wa -> waens`**.
step: **5. Apostrophe `-'s` ONLY for open vowel endings `i, o, u, a` (stressed!):** **`foto -> foto's`**, **`taxi -> taxi's`**, **`skadu -> skadu's`**, **`pa -> pa's`**, **`ma -> ma's`**, **`Israeli -> Israeli's`** (but **`ouma -> oumas`**, **`padda -> paddas`** — unstressed `a` takes NO apostrophe!).
```

## Part 2: Verkleinwoorde (Diminutives)

Notice how **diminutives NEVER drop twin vowels** (`boom` -> **`boompie`**, NOT `bompie`, and `maan` -> **`maantjie`**, NOT `mantjie`!):

| Ending of Root Word | Ending Added | Examples |
| :--- | :--- | :--- |
| **`l, n, r`** after **LONG** vowel / diphthong / `eu, ie, oe` | **`-tjie`** | *stoel -> **stoeltjie***, *skoen -> **skoentjie***, *deur -> **deurtjie***, *vrou -> **vroutjie*** |
| **`l, m, n, ng, r`** after **SHORT** vowel | **`-etjie`** (+ double consonant!) | *bal -> **balletjie***, *man -> **mannetjie***, *kom -> **kommetjie***, *ring -> **ringetjie***, *kar -> **karretjie*** |
| **`m`** after **LONG** vowel / diphthong / `l, r` | **`-pie`** | *boom -> **boompie***, *duim -> **duimpie***, *arm -> **armpie***, *besem -> **besempie*** |
| **Unstressed `-ing`** (drops `-g`!) | **`-kie`** | *koning -> **koninkie***, *piesang -> **piesankie***, *rekening -> **rekeninkie*** |
| **`d` or `t`** | **`-jie`** (after `d`: **`-tjie`**? NO: `hond -> **hondjie**`, `kat -> **katjie**`, `hoed -> **hoedjie**`, `voet -> **voetjie**`!) | *hond -> **hondjie***, *straat -> **straatjie***, *kind -> **kindjie*** |
| **Most other consonants (`k, p, g, f, s`)** | **`-ie`** (or **`-jie`** after `g` -> *vliegie*!) | *boek -> **boekie***, *aap -> **apie*** (`aa` drops one `a` in open syllable before `-ie`!), *kop -> **koppie*** (`p` doubles!), *kous -> **kousie***, *oog -> **ogie***! |
| **Open vowel (`a, o, u, i`)** | **`-'tjie`** | *ma -> **ma'tjie***, *foto -> **foto'tjie***, *baba -> **baba'tjie*** |

```compare
title: Spelling trap: Plural vs Diminutive of "boom", "kop", and "aap"
left: Twin vowels (`oo`, `aa`)
- **Plural (`-e`):** *bome*, *ape* (drops ONE vowel!).
- **Diminutive (`-pie`):** *boompie* (KEEPS both `oo`!), **EXCEPT `-ie` on `k/p/g/f/s`:** *aap -> **apie***, *oog -> **ogie***, *skaap -> **skapie*** (drops one vowel because `-ie` opens the syllable!).
right: Short vowels (`o`, `a`)
- **Plural (`-e`):** *koppe*, *katte*, *manne* (doubles consonant!).
- **Diminutive:** *kop -> **koppie*** (doubles `p`), *man -> **mannetjie*** (doubles `n` + `etjie`), *kat -> **katjie*** (does NOT double `t` before `-jie`!).
```

## Part 3: Geslag (Gender) & Versamelname (Collective Nouns)

- **Manlik -> Vroulik:** *man -> vrou*, *seun -> dogter*, *akteur -> aktrise*, *onderwyser -> onderwyseres*, *koning -> koningin*, *held -> heldin*, *prins -> prinses*, *leeu -> leeuin*, *bul -> koei*, *ram -> ooi*, *haan -> hen*, *hings -> merrie*.
- **Key Versamelname:** *'n **trop** skape/beeste/olifante*, *'n **swerm** voëls/bye*, *'n **skool** visse*, *'n **bos** sleutels/blomme*, *'n **tros** druiwe*, *'n **span** spelers*, *'n **klomp** kinders/klippe*, *'n **reeks** boeke/berge*.

## Worked example: Decoding tricky plurals & diminutives step by step

**Prompt:** *Gee die **meervoud** en **verkleinwoord** van:* `(a) stad`, `(b) skoen`, `(c) koning`, `(d) dag`.

- **(a) stad:** Plural = **`stede`** (irregular!); Diminutive (`d` ending) = **`stadie`? NO! Wait:** `stad` -> **`stadjie`** (`d` takes `-jie`, just like *pad -> paadjie* / *blad -> blaadjie*!).
- **(b) skoen:** Plural = **`skoene`** (`oe` stays `oe`!); Diminutive (`n` after `oe`) = **`skoentjie`**.
- **(c) koning:** Plural = **`konings`** (`-s`); Diminutive (unstressed `-ing`) = **`koninkie`** (drop `g`, add `-kie`!).
- **(d) dag:** Plural = **`dae`** (drops `g`!); Diminutive (short `a` + `g`) = **`daggie`** (doubles `g` + `-ie`!).

```tryit
title: Rapid plural + diminutive check
prompt: Skryf die korrekte **meervoud** én **verkleinwoord** van:
1. *skip*
2. *vlieg*
3. *foto*
4. *ring*
hint: Watch irregular `skip`, `-ie` after `g`, apostrophe on `foto`, and short `i` before `-ng`!
answer: 1. *skip* -> **skepe** | **skippie**
2. *vlieg* -> **vlieë** (`ie` + `ë`!) | **vliegie**
3. *foto* -> **foto's** | **foto'tjie**
4. *ring* -> **ringe** | **ringetjie**
```

> **Common mistakes**
>
> - Writing **`bomme`** or **`bome-pie`** — plural of `boom` is **`bome`** (1 `o`), diminutive is **`boompie`** (2 `o`s)!
> - Forgetting the apostrophe in **`foto's`** / **`ma's`**, OR wrongly adding an apostrophe in **`oumas`** / **`paddas`** (unstressed `-a` needs NO apostrophe!).
> - Writing `koningkie` instead of dropping `g`: **`koninkie`**.

```questions
Q: Gee die korrekte **meervoud** van die woorde tussen hakies: *Baie (skip) bring (baba) en (padda) na ons (stad) toe.* (4)
A: **skepe**, **babas** (of `baba's` aanvaarbaar, standaard `babas` / `foto's`), **paddas**, **stede**.

Q: Gee die korrekte **verkleinwoord** van: *(a) kat*, *(b) man*, *(c) oog*, *(d) piesang*. (4)
A: *(a)* **katjie**, *(b)* **mannetjie**, *(c)* **ogie**, *(d)* **piesankie**.
---
Q: Gee die **vroulike vorm** van *(a) akteur*, *(b) held*, en die **versamelnaam** vir *(c) 'n ___ visse*. (3)
A: *(a)* **aktrise**, *(b)* **heldin**, *(c)* **skool** (`'n skool visse`).
```

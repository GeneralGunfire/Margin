> **What you'll learn:** when Afrikaans **adjectives (*byvoeglike naamwoorde*)** take **`-e`** vs stay unchanged (**attributief vs predikatief**), **intensiewe vorme** (*pikswart, bloedrooi, doodstil*), **trappe van vergelyking** (*stellende, vergrotende, oortreffende trap* including irregulars *goed -> beter -> beste*), **voornaamwoorde** (*persoonlik, besitlik, betreklik `wat`/`wie se`*), and idiomatic **voorsetsels** (*op, aan, vir, met, in*).
>
> **Prerequisites:** noun spelling rules (open vs closed syllables, `f -> w`, `g` drops).
>
> **Why this matters:** Adjective inflection (`'n nuwe/ou/jong...`), relative pronouns (`die man **wat**...` vs `die man **vir wie**...`), and preposition choice account for a large share of Vraestel 1 language-editing questions AND mark the difference between awkward vs natural Afrikaans writing in Vraestel 3!

## Part 1: Byvoeglike Naamwoorde — When to add `-e`?

- **Predikatief (AFTER the noun / verb *is*):** NEVER adds `-e`!
  - *Die motor is **vinnig**.* | *Die huis is **oud**.*
- **Attributief (BEFORE a noun):**
  - **Adds `-e` if:**
    1. Root has **two or more syllables** (*'n **interessante** boek*, *'n **bekende** sanger*).
    2. Root ends in **`d, f, g, s`** (*'n **ou** huis* — WAIT: `oud` drops `d` + `e`?! Watch: **`'n ou man`** (`oud` -> `ou`), *'n **groot**? NO — `'n **kalt**? koud -> **koue** winter*, *'n **nuwe** (`nuut` -> `nuwe`) jas*, *'n **leë** (`leeg`) glas*, *'n **hoë** (`hoog`) boom*, *'n **sagte** (`sag`) kussing* — notice `d` drops in `oud -> ou` / `koud -> koue`, `f -> w` in `doof -> dowe`, `g` drops after long vowel in `hoog -> hoë`!).
  - **Does NOT add `-e`:** Most **short 1-syllable words** NOT ending in `d/f/g/s`!
    - *'n **mooi** blom* (NOT `mooie`!), *'n **groot** boom* (NOT `groote`!), *'n **swart** kat*, *'n **warm** dag*, *'n **klein** seun*!
  - **Figurative / Idiomatic exception (`-e` adds figurative punch!):** *'n **groot** man* (physically big) vs *'n **grote** man* (great/important man); *'n **koud**? -> `koue` water* vs *'n **harde** klip*.

## Part 2: Trappe van Vergelyking & Intensiewe Vorme

```steps
title: Rules for Trappe van Vergelyking (-er / -ste)
step: **Standard:** Add **`-er`** (*vergrotende trap*, with *as*) and **`-ste`** (*oortreffende trap*, with *die*): *lank -> **langer** -> die **langste*** (careful: **`lank -> langer -> langste`**, `k` becomes `g`!).
step: **Twin vowels / short vowels:** Follow plural spelling: *groot -> **groter** -> die **grootste***; *dun -> **dunner** -> die **dunste***.
step: **Ending in `-r` or `-s`:** Words ending in `-r` double the `r` (`duur -> **duurder** -> **duurste**`; `ver -> **verder** -> **verste**`); words ending in `-s` add **`-te`** (`vars -> varser -> **varste**` — only ONE `s`! NOT `varsste`!).
step: **Ending in `-e` / multi-syllable:** Use **`meer`** and **`mees`** (`opgewonde -> **meer opgewonde** -> die **mees opgewonde**`; `tevrede -> **meer tevrede**`).
step: **Must-know Irregulars:** **goed -> beter -> beste** | **baie / veel -> meer -> meeste** | **min -> minder -> minste** | **kwaad -> kwater -> kwaadste** | **jonk -> jonger -> jongste**.
```

### Key Intensiewe Vorme (ONE word, NEVER *baie* + word!)
- *baie swart* -> **pikswart** | *baie wit* -> **spierwit** | *baie rooi* -> **bloedrooi**
- *baie koud* -> **yskoud** | *baie warm* -> **vuurwarm / snikheet** | *baie stil* -> **doodstil / tjoepstil**
- *baie ryk* -> **skatryke / skatryk** | *baie arm* -> **brandarm** | *baie alleen* -> **moederzielalleen / stoksielalleen**
- *baie nuut* -> **splinternuut** | *baie oud* -> **stokoud** | *baie nat* -> **papnat**

## Part 3: Voornaamwoorde (Pronouns) — Especially Betreklike (`wat` vs `wie`)!

```compare
title: The #1 Pronoun Trap: `wat` vs `wie` (Relative Pronouns)
left: Use **`wat`** (WITHOUT a preposition!)
- **For BOTH people AND things** when acting directly as Subject or Object!
- *Die meisie **wat** daar staan, is my suster.* (NOT *die meisie wie daar staan*!)
- *Die boek **wat** ek lees, is spannend.*
right: Use **`wie`** / **`waarmee`** (ONLY AFTER a preposition or **`se`**!)
- **Person + preposition:** *Die vriend **met wie** ek praat...* / *Die onderwyser **vir wie** ons werk...*
- **Possession (`whose`):** *Die kind **wie se** fiets gesteel is...* (person OR thing: *Die huis **waarvan** die dak lek...* / *wie se*!)
- **Thing + preposition:** NEVER say *die pen met wat*! Combine **`waar` + preposition**: *Die pen **waarmee** (`met + wat`) ek skryf...*; *Die stoel **waarop** (`op + wat`) jy sit...*!
```

### Besitlike & Wederkerende Voornaamwoorde
- **Besitlik (*possessive*):** *my -> myne*, *jou -> joune*, *sy -> syne*, *haar -> hare*, *ons -> ons s'n*, *hulle -> hulle s'n*.
- **Wederkerend (*reflexive*):** *Ek skaam **my**.* | *Hy verbeel **hom**.* | *Ons haas **ons**.* | *Hulle bekommer **hulle**.* (NOT `hulle self` for standard reflexive verbs like *skaam, bekommer, verbeel, haas*!)

## Part 4: High-Frequency Voorsetsel (Preposition) Traps

| English Literal Trap | Correct Idiomatic Afrikaans |
| :--- | :--- |
| *excited about* | **opgewonde oor** |
| *angry at / with* | **kwaad vir** |
| *afraid of* | **bang vir** |
| *proud of* | **trots op** |
| *interested in* | **belangstel in** (`belang in`) |
| *listen to* | **luister na** (NOT *vir*!) |
| *wait for* | **wag vir** |
| *pay for* | **betaal vir** |
| *on holiday / at school / by bus* | **met vakansie / by die skool / per bus (met die bus)** |

## Worked example: Editing adjectives, relative pronouns & prepositions together

**Prompt:** *Korrigeer die vier taalfoute in hierdie sin:*
`Die seun wie so baie koud het, luister vir die nuut radio wat op sy oom sit.` *(intended: whose new radio sits on his uncle's table — wait: let's fix cleanly!)*
Correction drill: `Die meisie wie baie kwaad aan my is, sit met 'n nuut rok en luister vir musiek.`
1. `wie` (no preposition!) -> **`wat`**
2. `kwaad aan` -> **`kwaad vir`**
3. `'n nuut rok` -> **`'n nuwe rok`** (`nuut` ends in `t`? Remember `nuut -> nuwe`!)
4. `luister vir` -> **`luister na`**
- **Corrected:** *Die meisie **wat** baie kwaad **vir** my is, sit met 'n **nuwe** rok en luister **na** musiek.*

```tryit
title: Test all four skills in one short drill
prompt: Vul die korrekte woorde in:
1. *Hierdie stoel is nog (goed), maar daardie een is (baie goed - oortreffende trap).*
2. *Die dame (who) ek die brief (to) gestuur het, woon in 'n (oud) huis.*
3. *Die tafel (on which) die koppie staan, is (baie skoon - intensiewe vorm).*
hint: Check irregular `goed`, `aan wie`, `oud -> ou`, and `waar + op`!
answer: 1. *goed*, **die beste**
2. **aan wie**, **ou** (*'n ou huis*)
3. **waarop**, **silwerskoon** (of **blinkskoon**)
```

> **Common mistakes**
>
> - Writing **`die meisie wie...`** instead of **`die meisie wat...`** when there is NO preposition before it!
> - Writing **`die pen met wat`** instead of **`die pen waarmee`**.
> - Writing **`nuutste -> nuutste`** vs **`nuwe`** (`'n nuut jas` is WRONG — always **`'n nuwe jas`**), or adding `-e` where it doesn't belong (`'n mooie rok` -> WRONG; **`'n mooi rok`**!).
> - Using literal English prepositions (*"trots van"*, *"kwaad met"*, *"luister vir"*) instead of **`trots op`**, **`kwaad vir`**, **`luister na`**.

## Practice

```questions
Q: Gee die korrekte vorm van die byvoeglike naamwoorde tussen hakies: *My oupa bly in 'n (oud) huis met 'n (hoog) dak en 'n (leeg) dam.* (3)
A: **ou**, **hoë**, **leë**.
---
Q: Verbind met 'n betreklike voornaamwoord: *Dit is die skêr. Ek sny die papier met die skêr.* (2)
A: **Dit is die skêr waarmee ek die papier sny.** (`met + wat` -> **`waarmee`**, en `sny` skuif na die einde!)
---
Q: Vul die korrekte voorsetsels in: *Ons is baie trots (1) ons skool, maar ons is bang (2) die eksamen.* (2)
A: *(1)* **op** (*trots op*), *(2)* **vir** (*bang vir*).
```
